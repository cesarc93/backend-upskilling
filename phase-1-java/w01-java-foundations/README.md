# MI PROGRESO

## Día 1
**Fundamentos y configuración del entorno:** Configuré el repositorio multi-módulo con Java 17 y Maven, y construí los primeros ejercicios de fundamentos con sus pruebas unitarias en JUnit 5. Aprendí qué es Maven, cómo funciona el pom.xml para gestionar dependencias y construir el proyecto, y cómo escribir pruebas en Java. Lo que más se me complicó fue entender Maven y JUnit 5.

## Día 2

**Control de flujo y pruebas unitarias:** Implementé los ejercicios de control de flujo en Java junto con la lectura por consola con `Scanner`, separando la lógica pura de la interacción por CLI para probarla de forma automatizada con JUnit 5. Lo más complicado fue aprender a diseñar clases de lógica aisladas de la consola, a validar casos normales y de error en pruebas unitarias. Aprendí a usar los comandos principales de Maven (`validate`, `test`, `package` y `verify`) junto con la configuración de `junit-jupiter` en el `pom.xml`.*.
